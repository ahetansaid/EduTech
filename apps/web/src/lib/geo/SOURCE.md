# Limites administratives

- Source : geoBoundaries (gbOpen), BEN ADM1 et ADM2, version simplifiée — https://www.geoboundaries.org
- Licence : ouverte (voir les métadonnées geoBoundaries du jeu BEN).
- Traitement : coordonnées arrondies à 3 décimales ; rattachement commune → département par
  point-dans-polygone, trois corrections manuelles (Dogbo → Couffo, Ifangni → Plateau,
  Grand-Popo → Mono) ; noms accentués selon l'usage officiel.
- Répartition obtenue : 12 départements, 77 communes.
